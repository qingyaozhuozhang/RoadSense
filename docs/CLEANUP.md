# RoadSense 项目文件组织与信息保护说明

## 1. 项目文件构成

RoadSense 项目由云端服务、边缘计算节点、Android 移动巡检终端以及相关技术文档组成。源代码目录分别为 `qianduan/`、`houduan/` 和 `Android_Studio/`，系统级技术说明集中在项目根目录和 `docs/` 下。

交付内容包括 Flask 服务端、网页前端、边缘道路损伤检测与双目测距程序、GNSS 数据解析模块、Android 应用源码、ONNX 模型、必要的部署文件以及测试程序。

## 2. 运行数据与源码的边界

业务运行产生的 SQLite 数据库、归档照片、运行日志、缓存、虚拟环境和编译输出均属于运行环境数据。数据存储位置应依据配置及实际部署环境确定，不能仅根据源代码目录推断云端已保存的用户、设备和巡检记录。

完整业务备份需要同时包含数据库与归档照片，方法参见 [数据备份与恢复规范](DATA_BACKUP.md)。

## 3. 配置与凭据保护

系统使用 Flask 会话密钥、设备认证令牌、地图服务密钥及移动应用签名证书等凭据。配置文件可能包含真实部署参数，公开发布前应审查以下内容：

- `qianduan/.env`、`houduan/.env` 等运行环境配置；
- Android 构建配置中的云端地址与第三方服务 Key；
- 用于应用签名的 Keystore、密码及本地 SDK 配置；
- 用户数据、定位记录、归档照片及可能包含敏感信息的日志。

在公开仓库中不宜提交生产密钥或真实用户数据。需要分发运行配置时，应采用受控渠道，并根据部署范围管理凭据有效期及权限。

## 4. 文件维护原则

文档以当前系统功能、架构和运行条件为描述对象，采用统一的技术术语，不记录与系统使用无关的个人信息、临时调试过程或设备替换流水。部署配置、数据库备份和应用签名资料应与公开技术文档分开管理。
